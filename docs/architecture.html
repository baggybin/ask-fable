ask-fable · MCP server

A council of oracles,
behind one gate.

ask-fable is a Model Context Protocol server that lends an agent a second brain: external reasoning models reached through 37 guarded tools, called directly or orchestrated as councils, chains, and debates, with reusable context and correlated traces.

The main artery

02What one ask call does

The full journey of a single multi-turn call — from raw arguments to a saved answer. Every hop names its module. server.py · _handle_ask()

1

Parse & reset sessions.py

Pull question, session, reset. If reset=true, dump the old transcript to markdown and clear it — so ref counts only see post-reset context.

2

Resolve context context_store.py

Merge inline context with any context_ref keys pulled from the SQLite context store. If every ref is missing and there's no other context or history — fail fast, never call the model.

all refs missing → needs_context
3

The gate guard.py

Two layers: sanity (length & size bounds), then ask-fable's bundled prohibited-use denylist. Denied calls are audited and refused here — the model is never reached.

passed → continuedenied → refused · stage: guard
4

Dispatch to Fable fable.py

Call fable.run() with the session's resume id. The Agent SDK runs in-process (reusing ~/.claude OAuth — no API key); if unavailable it falls back to the claude CLI. Thinking blocks are captured; reasoning can stream live to stderr.

refused → stage: modelerror → kind + detailok → continue
5

Extract sidecar & guard the loop sidecar.py

Strip the ```json-sidecar block from the prose. If the recommendation is needs_more_context, bump the session's blocked streak — past the cap (default 2) the call returns context_exhausted to stop an agent's re-ask loop.

6

Record the turn sessions.py · audit.py

Save the SDK session id + (q, a, thinking) to the in-memory transcript for the next resume. Append one JSONL decision record — hashed question, model, latency, consensus fields — to the audit log.

7

Persist & return outputs.py

Write the answer (plus thinking & sources) to a timestamped markdown file, then return the JSON body: status · model · answer · sidecar · session — plus optional thinking, ref attribution, follow-up hints, and saved-file path.

The engine room

03One interface, multiple bridges

Every backend hides behind oracles.run(key, …) and returns the same shape. The registry checks the cache, then the circuit breaker, then routes by key — and records the outcome for both.

common contract OracleResult( status, key, text, kind, model, thinking, session_id )
FableSDK / CLI
fable.py · newest claude-fable-*

In-process Agent SDK, OAuth-reused, multi-turn resume. The only stateful oracle — and the council's synthesizer. Not pinned to an id: it asks for the newest Fable and steps down a rung if the local Claude Code is too old to run it.

Claude Opus 5SDK / CLI
opus.py · claude-opus-5

Same OAuth session and multi-turn model as Fable, in its own session namespace. Roughly half the price, noticeably faster.

Anthropic-Messages envelope parsed from CLI stdout. Stateless.

Gemini 3.1 ProCLI

Raw stdout answer; SIGKILLs the whole process group on timeout.

GPT-5.6 SolCLI

GrokCLI

The scaffolding

05Cross-cutting subsystems

Fourteen modules wrap every call with safety, memory, resilience, and observability — each best-effort, none allowed to crash a turn.

guardguard.py

Two-layer gate: sanity bounds + prohibited-use denylist. Model scope (software only) is enforced separately in the system prompt.

sessionssessions.py

In-memory Fable transcripts + resume ids + the blocked-streak counter. Thread-locked; dumps to markdown on reset.

context storecontext_store.py

Durable keyed blobs in SQLite (WAL). Kills the re-paste tax — write once, context_ref forever.

healthhealth.py

Per-oracle circuit breaker: closed → open → half-open. Auto-skips chronically failing backends; ignores scope/config non-failures.

cachecache.py

Best-effort answer cache for single-shot + council + chain (never multi-turn ask). Keyed on tool+models+question+context hash, 1h TTL.

sidecarsidecar.py

The machine-readable contract: a json-sidecar fence carrying recommendation, confidence, and needs-context — stripped from prose, trusted only if unambiguous.

auditaudit.py

Append-only JSONL, one record per decision. fcntl-locked + fsync'd, question hashed by default, size-rotated at 50MB.

statsstats.py

Read-only aggregation of the audit log into calls / errors / p95 latency, bucketed by model, session, or day.

consoleconsole.py

Boxed, colorized progress + reasoning to stderr — stdout stays pure JSON-RPC. Streams Fable's thinking live when asked.

outputsoutputs.py

Every successful answer atomically written to timestamped markdown — question, context, answer, thinking, and council sources.

configconfig.py

Tool-writable JSON store. Precedence: config file → env var → default. Atomic writes persist the Ollama council across restarts.

session hubhub.py

Visibility-only mirror of successful turns across local MCP instances — list, peek, and aggregate by label. Never read by the oracles.

tracestrace_store.py · trace_runtime.py

Schema-v2 correlated request timelines; safe mode stores metadata only, full mode writes redacted, size-capped bundles.

paths_paths.py

XDG dirs + secure I/O: 0700 dirs, 0600 files, atomic tempfile + rename + fsync everywhere — no world-readable window.
