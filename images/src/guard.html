The guard — three layers

Layers 1–2 run locally before any model call. Layer 3 is Fable’s system prompt at inference.

1
PRE-CALL

Sanity floor

  • Rejects empty, too-short (<3 chars), or too-long (>65536 chars) questions.
  • Context is unbounded; any cap is floored to 512,000 chars.
  • Breadth is allowed — this is a size check, not a topic filter.

On fail: return refused. No model call.

→
2
PRE-CALL

Prohibited-use denylist

  • Bundled offensive-security and biology dual-use patterns.
  • Extend with ASK_FABLE_DENYLIST_FILE (one term per line).
  • Allowlist phrases (e.g. request payload) neutralize false trips.

On fail: return refused. No model call.

→
3
AT INFERENCE

Model scope contract

  • Fable’s system prompt: engineering questions are in scope, including conceptual ones.
  • Replies REFUSED: <reason> only for direct offensive-security asks or non-software domains.
  • Questions about security-related code are normal engineering.

On fail: the model replies REFUSED: <reason>.
